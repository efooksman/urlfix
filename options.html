Tips

        
    
          
  • Toggle: Use the switch to enable/disable rules without deleting them
    • 
          
  • Allow rules: Use to create exceptions (e.g., "don't redirect if X is already present")
    • 
          
  • Priority: Higher number = checked first. Use priority 2 for "allow" exceptions, priority 1 for redirects
    • 
          
  • Capture groups: Use (pattern) in regex, reference with $1, $2 in replacement
    • 
          
  • Escape special chars: Use \\. for literal dot, \\? for literal question mark
